# Juan Jose Carracedo

Software engineer at **A-Safe Digital**, based in Málaga, Spain. I build developer
tooling and UI infrastructure — mostly around Ruby on Rails and Hotwire, but also
native macOS apps in Swift, infrastructure-as-code on Terraform and Ansible, and
tools that let AI agents drive real software instead of just autocomplete it.
I care about accessibility, honest limitations docs, and correctness that is
verified against the original rather than asserted.

## Featured work

- **[hotwirebits](https://github.com/DonsWayo/hotwirebits)** — An open-source UI component library for Rails with 240+ components and 99 Stimulus controllers, shipped both as ERB partials and ViewComponent classes on Tailwind CSS v4. `Ruby`
- **[hotwire-flow](https://github.com/DonsWayo/hotwire-flow)** — A React Flow–style node-based editor rebuilt on plain HTML with Stimulus and Tailwind, so graph editors work without a JavaScript framework. `JavaScript`
- **[consai](https://github.com/DonsWayo/consai)** — A menu-bar-first macOS app for Apple's `container` and `container-compose` stacks: live CPU, memory and IP per container, without Docker Desktop. `Swift`
- **[odoo-addons](https://github.com/DonsWayo/odoo-addons)** — Odoo 19 modules, including `dw_git`: self-hosted Git repository hosting with pull requests, reviews, tokens and diffs as native Odoo records. `Python`
- **[pi-actions](https://github.com/DonsWayo/pi-actions)** — A self-hosted GitHub Actions runner fleet on Raspberry Pi, fully bootstrapped by Terraform, Ansible and cloud-init — flash the card, power on, it registers itself. `Shell`
- **[tauri-mcp](https://github.com/DonsWayo/tauri-mcp)** — A Tauri plugin exposing screenshots, DOM inspection and input simulation over the Model Context Protocol, so coding agents can test desktop apps end to end. `Rust`
